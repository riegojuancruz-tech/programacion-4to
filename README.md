# Programación — 4to Año
 
Repositorio de la materia. Vamos a aprender **Python** desde cero, cubriendo los fundamentos del lenguaje hasta el manejo de diccionarios, y vamos a cerrar el año aplicando todo lo aprendido en el desarrollo de **un videojuego**.
 
## 🎯 Objetivos de la materia
 
- Comprender la lógica de programación y el pensamiento computacional.
- Aprender la sintaxis y las herramientas fundamentales de Python.
- Aplicar los conceptos en la construcción de un proyecto final: un videojuego.
- Desarrollar habilidades de resolución de problemas, trabajo en equipo y pensamiento crítico.
## 🗂️ Contenidos
 
### Unidad 1 — Introducción a Python
- ¿Qué es programar? ¿Qué es un lenguaje de programación?
- Instalación y configuración del entorno (Python + editor de código)
- Variables y tipos de datos (`int`, `float`, `str`, `bool`)
- Entrada y salida de datos (`input()`, `print()`)
- Operadores aritméticos, de comparación y lógicos
### Unidad 2 — Estructuras de control
- Condicionales: `if`, `elif`, `else`
- Bucles: `while` y `for`
- `range()` y control de flujo (`break`, `continue`)
### Unidad 3 — Estructuras de datos
- Listas: creación, indexado, métodos y recorrido
- Tuplas
- Sets (conjuntos)
- Diccionarios: claves, valores, métodos y recorrido
### Unidad 4 — Funciones
- Definición y uso de funciones (`def`)
- Parámetros, argumentos y valores de retorno
- Alcance de variables (scope)
- Funciones como herramienta para organizar el código
### Unidad 5 — Proyecto final: Videojuego 🎮
- Diseño del juego: idea, mecánicas y objetivos
- Introducción a la librería que usemos (por ejemplo, `pygame`)
- Manejo de eventos, sprites y colisiones
- Aplicación práctica de variables, condicionales, bucles, listas y diccionarios
- Iteración, testing y mejora del juego
- Presentación final del proyecto
## 🛠️ Requisitos
 
- Python 3.x instalado ([python.org](https://www.python.org/downloads/))
- Un editor de código (recomendado: [VS Code](https://code.visualstudio.com/))
- Librería `pygame` (se instala más adelante, cuando lleguemos al proyecto)
Para instalar `pygame` cuando corresponda:
 
```bash
pip install pygame
```
